Notes on what's NOT printed above, and why:
- The first event has no "userId" key at all: `JSON.stringify` omits object
  keys whose value is `undefined`, and `identify()` has not been called yet
  when this event is built, so `userId` is `undefined` at that point.
- The second event has no "context"/"metadata" keys, for the same reason:
  the second `track()` call passes no `TrackOptions`, so both are
  `undefined` and dropped by `JSON.stringify`.
- Both events share the same `anonymousId` and `sessionId` -- this process's
  identity/session state (generated once when `createAnalytics()` is called)
  never changes across calls unless `reset()` is called.
- The second event's `userId` is `"user_42"` -- the exact value passed to
  `identify()` between the two `track()` calls.
